# S Kesava Prasaath — Portfolio

A lightweight static engineering portfolio with a bright, editorial visual system inspired by project-first maker portfolios.

## Files
- `index.html` — page structure and content
- `styles.css` — visual system, responsive layout, typography
- `script.js` — scroll reveals, marquee and live drafting background
- `images/` — project and profile images

## Local preview
Open `index.html` directly in a browser, or serve the folder with any static HTTP server.

## Update flow
Replace or add images in `images/`, update the corresponding project card in `index.html`, then commit and push to GitHub. Vercel will redeploy automatically.
