# Kesava Prasaath — Portfolio Website

A single-page robotics/mechatronics portfolio inspired by:
- Robrotics: dark, technical, industrial visual language and engineering-first presentation.
- Aaed Musa: project-led personal portfolio structure and clear separation of projects/about/contact.

## Files
- `index.html` — page structure and portfolio copy
- `styles.css` — responsive visual design
- `script.js` — scroll reveal and marquee animation

## Personalise
1. Replace `your.email@example.com` with your real email.
2. Replace the `#` social links with your profiles.
3. Replace the four project cards with your final project images and links when ready.
4. Deploy the folder to GitHub Pages, Netlify, Vercel, Firebase Hosting, etc.
